# Handbook

컴퓨터과학과 영어를 공부할 수 있는 모바일 중심의 시험 대비 핸드북입니다. 컴퓨터과학개론, AI리터러시, C프로그래밍, 대학영어, 자료구조, 컴퓨터구조를 다룹니다.

44개 단원에 핵심 이론, 개념 비교표, 단계별 예제, 암기 노트를 제공합니다. 복잡한 개념은 그림과 함께 살펴볼 수 있습니다. 142개 자체 제작 문항은 답을 선택하면 바로 채점하고 풀이를 보여 줍니다. 대학영어 지문도 독해 연습을 위해 자체 제작했습니다.

진도와 정답률은 현재 브라우저에 저장됩니다. 문항별로 마지막 채점 결과를 반영하며, 오답을 다시 풀어 맞히면 복습 목록에서 빠집니다.

브라우저에서 HTML, CSS, JavaScript로 동작합니다. 한글 본문에 Noto Sans KR을 사용합니다.

| 위치 | 역할 |
| --- | --- |
| `dist/index.html` | 공통 화면 틀과 메뉴 |
| `dist/courses/` | 과목별 학습 내용과 문제 |
| `dist/app.js` | 화면 이동과 진도·오답 기록 |
| `dist/quiz.js` | 퀴즈 화면, 즉시 채점과 풀이 |
| `dist/diagrams.js` | 학습 도식 |
| `dist/style.css`, `dist/logo.css`, `dist/icons/` | 레이아웃, 워드마크와 아이콘 |
