# 시험 대비 핸드북

컴퓨터과학과 영어를 학습할 수 있는 모바일 중심 웹 핸드북입니다. 이론·비교표·예제·암기 노트를 읽고 자체 제작 객관식 문제로 이해도를 확인할 수 있습니다.

AI리터러시, C프로그래밍, 대학영어, 컴퓨터과학개론, 자료구조, 컴퓨터구조를 다룹니다. 과목별 진도와 오답 복습 기능을 제공합니다.

## 로컬 실행

저장소 폴더에서 Python 3로 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

브라우저에서 [http://127.0.0.1:8000](http://127.0.0.1:8000)을 엽니다. 같은 Wi-Fi의 휴대폰에서 확인하려면 바인딩 주소를 `0.0.0.0`으로 바꾸고 휴대폰에서 맥의 로컬 IP와 포트 8000으로 접속합니다. 종료하려면 Ctrl+C를 누릅니다.

## Vercel 배포

1. GitHub 원격에 원하는 배포용 브랜치를 푸시합니다.
2. Vercel에서 **Add New → Project**로 해당 저장소를 가져옵니다.
3. 루트는 저장소 루트, Framework Preset은 **Other**, Output Directory는 **dist**를 사용합니다. `vercel.json`에 설정을 포함했습니다.
4. 배포하면 발급된 주소에서 접속할 수 있습니다. 이후 연결된 브랜치에 푸시하면 재배포됩니다.

## 학습 기록

풀이 진도는 한 번 이상 채점한 문항 수입니다. 정답률과 오답 노트는 문항별 최근 채점 결과를 사용합니다. 오답을 다시 풀어 맞히면 목록에서 빠집니다. 단원을 읽은 뒤 읽기 완료를 직접 표시할 수 있습니다. 기록은 접속 주소와 브라우저에 저장됩니다.

과목 자료는 `dist/courses/` 아래에 있으며 화면·채점·기록 저장은 `dist/app.js`에서 공통으로 처리합니다. 한글 글꼴은 Noto Sans KR을 우선 사용하고 글꼴을 불러오지 못하면 기기의 기본 글꼴을 사용합니다.
